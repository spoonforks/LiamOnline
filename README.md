# LiamOnline

Liam Cunningham's interactive portfolio website.

The site is a static, offline-first experience with an animated Game of Life background, education map, academic portfolio, and personal tools. Desktop visitors can explore the academic work in an interactive 3D museum; mobile and touch devices receive a lightweight project gallery with direct links instead.

## Run locally

Open `index.html` directly, or serve the directory with any static file server:

```powershell
python -m http.server 43117 --bind 127.0.0.1
```

Then open `http://127.0.0.1:43117/index.html`.

## GitHub Pages

The static entry point and all required assets are stored at the repository root, ready for GitHub Pages to be enabled later.
